# Implementação em C++ (CPLEX)

Arquivos desta pasta:
- `PL.cpp`: Implementação da função de verificação de caminho válido (Atividade 1), resolução da relaxação linear (Atividade 2) e resolução do modelo inteiro com limite de 3 minutos (Atividade 3).
- `readFile.h` e `readFile.c`: Leitura das matrizes de adjacência/custos das instâncias `.atsp`.
- `Makefile`: Script de compilação para ambiente Linux com CPLEX ou Windows com MinGW (`g++`).
